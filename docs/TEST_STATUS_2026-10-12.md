## 4. 可复核入口

普通单元测试：`PYTHONPATH=src python -m unittest discover -s tests -v`。

模拟完整流程：安装固定的 Snakemake 9.27.0 后执行 `PYTHONPATH=src python tests/integration_smoke.py`。模拟工具不会调用真实 EDTA/TEtrimmer。

蛋白数据库小测试：`TEFLOW_TEST_BLAST_BIN=/实际/BLAST/bin PYTHONPATH=src python tests/integration_teaid.py`，只使用一条合成蛋白。

测试名称和适用范围均写在代码中。精简复核包不含真实数据、原始日志或个案恢复历史，评审者应结合以上已完成/未完成边界阅读代码。
