## 新审核回归检查

新增 15 项单元检查覆盖双链、双向 gap、核酸序列不一致、坐标错误、数字染色体 ID、变长 FASTA 行、混合最终/原始家族、GTF/GFF3 父链与 isoform、原生 RC 别名、全 N 拒绝、缺注释与无蛋白命中的显式状态、BTOP/frame 消耗、旧 alignment 原目录匹配、独立目录完整性、失败回执、人工接纳字段和无启动子时的基因上下文导出。

真实 DIAMOND 检查中，两个独立蛋白区段之间设置非同源间隔，使 HSP 在 query/subject 上均不包围。相同 query 重复片段映射到同一个 subject 范围不满足这个条件；`--max-hsps 0` 不能保证报告所有此类重复匹配。这是上游语义，不能改写为本框架已经穷尽全部蛋白相似性。

## 真实数据回放结果

新模块重新得到 42,586 条最终注释的连接分类：38,504 条同原始家族、3,663 条混合原始家族、287 条仅不同原始家族、132 条部分或未覆盖。这些是来源/坐标关系，不是生物学准确率。

11 个原生候选全部通过非 N 序列回抽核对。H0000139/EH0000895 的原生区域仍含 11,929 bp 注释 CDS，6 个基因的完整 CDS 并集；H0000134/EH0000890 原生 CDS 重叠为 0，与前次审核一致。仅凭后者为 0 仍不能宣称其是真阳性或安全屏蔽来源。

准备的 121 个位点是有限、确定性取样；其中 110 个是 raw alignment fragment，不能计为 110 个完整插入。输出侧翼便于后续使用既有工具核对端点，目前没有自动边界裁剪。
