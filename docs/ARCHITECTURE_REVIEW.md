# TE annotation workflow 0.4.0：第三方架构复核入口

本包是通用 TE 注释与审核工作流，未包含 mfuzz/pCRE/PROPEL 算法。请评估代码和已登记证据，不将阶段完成回执理解为生物学正确性证明。拟南芥 v022 五分支已完成计算；0.3 新增独立局部审核。工具安装、模拟验收、真实小型依赖检查、真实数据回放和生物学准确率有不同证据等级。

## 需要重点质疑的设计选择

1. HELIANO 默认采用原生片段模型，并用 EDTA 非 HLE 清理；这与“完全独立的 HELIANO 共识库”不同。是否应另设严格独立探索路线，必须通过新实验而非改名解决。
2. HiTE 携带同源资料和训练模型；镜像散列可复现运行环境，但不能使拟南芥参考评价自动独立。需要保留参考泄漏/暴露说明。
3. 精确别名组装故意不解决近似家族冗余。它便于保留证据，但不能被描述成成熟的库整合/去冗余算法。
4. GC、长度、宿主蛋白与域命中为审核证据；缺少域、短序列或宿主相似性均不能单独证明非 TE。HELIANO 清理选择的特定过滤条件须与通用 QC 区分。
5. 新配置关闭启动子分析；显式启用时，gene-boundary 仍只是暂定区域。它不参与 TE 候选筛选。检查关闭时是否仍可完成全套基因组导出，旧缺省配置是否保持原语义。
6. CPU affinity 可约束 Linux 子进程选核；Snakemake mem_mb 仍是调度声明。是否需 cgroup/Slurm 约束应由部署环境确认。
7. 同一运行仍使用全局源码/软件冻结，添加分支采用新 run+显式 EDTA/RM 导入；它不是任意阶段随时跨版本复用系统。
8. 参考只支持坐标/类别的描述性比较；本版尚无完整插入边界、人工共识家族敏感度和跨物种准确率验证。不要用缺失结果支持任何工具排名。

## 建议反馈格式

请按影响排序，分别指出实现错误、协议选择、科学证据不足与工程增强。每条给出触发条件、代码位置、风险和最小验证方法。重点寻找静默成功、坐标错位、来源丢失、重复计算、假缓存及资源失控的具体案例。

本版 zip/tar.gz 不包含数据库、真实基因组、大型镜像、原始比对和完整运行日志；必要的模拟测试、轻量实测摘要、锁定版本与上游源码核查散列随包提供。保留历史故障脚本以支持回归，但它们不是本版新运行的必经步骤。

新增审查重点：局部取样是否被误解为完整插入集合；宿主参考中的 TE 编码基因/转录本选择是否被过度解释；解除 DIAMOND 报告上限是否被误称为穷尽检索；人工接纳接口是否把来源混合的最终 RM 家族粗略删去；相同捕获候选能否合理地留在生物学目录而从某种屏蔽用途中排除。禁止用未运行的服务器 QC 结果填补这些问题。
