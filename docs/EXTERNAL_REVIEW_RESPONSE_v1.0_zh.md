# 0.7 外部评审后的 1.0 决策

日期：2026-10-22。依据：0.7.0rc1 源码、10 月 22 日模拟验收、0.6 TAIR10 原始反馈。总体采纳“先完善日常使用，再扩展分析”的方向。1.0 表示单物种软件接口的首发收敛，不增加跨物种准确性声明。

## 必须纠正的事实与推断

1. **QC 用时短不能推出没有运行 DIAMOND。** 原始反馈 `work/arabidopsis_TAIR10/qc_edta/host.makedb.log.command.json` 和 `host.blastx.log.command.json` 均为成功退出；`qc.json` 明确写 `host_protein: executed`。因此“本次 H 清理没有宿主蛋白证据”这一前提不成立。仍需审核其生物学充分性，但不能基于该错误前提改变默认协议。
2. **ET 未保留亲本为 517 个。** 732 个输入对应 215 个有后代的唯一亲本，而不是用 223 条输出相减；同一亲本可以有多条输出。新增报告计算唯一亲本与 E 注释区间并集，缺少原始表时如实标为未知。
3. **EH 的 1.24 Mb 和 1.39 Mb 来自不同时期运行。** 当前 v0.6 净增 1,393,453 bp；EH-only 为 1,397,240 bp，E-only 为 3,787 bp。不能混用，也不能解释为新增真实 TE 的真值。
4. **发行名、导入名、仓库名不同不是缺陷。** 保留已有 `te-annotation-workflow` / `teflow` / TEflow 对应关系并说明。ORCID 为可选字段，不能凭空补写；项目方已确认作者 Feiyu Chen 与 ORCID 0009-0008-5269-5023，已写入 CITATION.cff。
5. **单 CPU 测试统计存在算术不一致。** 评审写的 162 通过 + 1 跳过 + 3 失败不等于 165。我们按实际测试重新登记；已修正需要两个 CPU 的测试条件，其余可在单 CPU 上运行的测试继续执行。

## 暂不照搬

- **P2-1 RM 默认线程**：提供显式 32 核预算的平衡请求示例；本轮不依据未经对照的速度推断改变默认。增加线程不等于保证加速。
- **P2-4 内存准入**：不改成仅提示性。共享节点上的预算可能过大，应改善解释和显式请求，而不是放弃准入保护；无限等待也不是对所有用户合理的默认。
- **P2-11 宿主蛋白 QC**：维持显式启用，真实运行已有执行证据。改变其默认会影响 H 清理输入，需要单独的科学协议比较。
- **P2-5/P2-8 阶段重开和细粒度跨版本复用**：需要确认下游失效、旧目录身份和生产者契约，不能仅改一个版本字符串。旧结果继续可读、可选择；不承诺任意阶段跨版本复用。
- **I1–I4**：RM group ID 不能直接升级成完整插入事件，拷贝聚合须验证家族、链和跨度；BED6 score 也不能直接使用未规范化的浮点分歧度。表达 GTF 必须针对目标工具验证；区域富集的零模型是新的统计方法责任。这些超出首发的结果接口整理。
- **P3-2 启动子缺省**：新 init 已关闭；旧配置缺省行为保留以避免改变历史语义。未来迁移应显式记录默认，不在旧配置中静默切换。
- **日志错误关键词**：未复现良性日志误报，不直接移除已有失败防护。需要具体上游样例后调整。
- **自动清理、PSS、新工具和近似融合**：分别涉及恢复契约、监控成本与科学范围，进入后续路线，不在此次一并引入。

## 下一轮证据

优先用既有结果生成 ET 覆盖与基因区分层审核，再做固定库 R 分支重放、RM 参数对照和真实容器小型取消/临时目录验证。这里的 CDS 重叠只是描述性证据，不能单独把覆盖标成过度屏蔽。完整原始表未包含在小反馈包中时，应由服务器只读生成报告，不伪造数值，也不重跑发现阶段。

文献扩展暂不纳入：景观工具接口、TEsorter/REXdb、保守基因证据等可在各自官方版本和用途验证后添加为离线模块。当前优先发布清楚、可审计的通用 TE 工作流。
